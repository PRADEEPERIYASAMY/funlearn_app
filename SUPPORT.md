# Support

FunlearnV2 is a solo side project, not a commercially supported product. This document describes how to get help and what kind of support to realistically expect.

## Getting Help

**For bugs and reproducible issues**, open a [bug report](https://github.com/PRADEEPERIYASAMY/FunLearnV2/issues/new?template=bug_report.md). Include device, Android version, and steps to reproduce.

**For questions about how the code works**, use [GitHub Discussions](https://github.com/PRADEEPERIYASAMY/FunLearnV2/discussions) if enabled, or open a regular issue with a clear question. Check the README sections first — the architecture and feature notes cover most design decisions.

**For feature requests**, use the [feature request template](https://github.com/PRADEEPERIYASAMY/FunLearnV2/issues/new?template=feature_request.md).

**For security vulnerabilities**, do not open a public issue. Follow the process in [SECURITY.md](../SECURITY.md).

## What to Expect

- Issues are reviewed when time allows. There is no SLA.
- Bugs that affect core functionality (auth, data layer, chat) are prioritized.
- Requests for help integrating this code into a separate project are out of scope.
